## Highlights

- This is the first versioned release of the MotherDuck Dive and AI Chat Starter. It embeds a saved MotherDuck Dive next to an AI assistant that answers questions about the data behind the Dive and shows the SQL it used. ([README](https://github.com/leonardovida/motherduck-dive-ai-chat-starter/blob/v0.1.0/README.md))
- The README now addresses business users and coding agents as well as developers. It offers three setup paths: delegate setup to a coding agent, run the starter locally, or deploy it to Vercel. ([README](https://github.com/leonardovida/motherduck-dive-ai-chat-starter/blob/v0.1.0/README.md))
- Releases are now versioned. Each release has a Git tag, a GitHub Release and an entry in the changelog, so teams can start from a known version and upgrade deliberately. ([Releasing guide](https://github.com/leonardovida/motherduck-dive-ai-chat-starter/blob/v0.1.0/docs/releasing.md))

## Features

- Embedded Dives:
  - Each configured Dive opens through a short-lived embed session that the server creates. The session runs as a named read-only service account.
  - The sidebar lists any number of Dives from `dives.config.mjs`. Each Dive has its own optional data shares and chat database.
  - The light and dark themes reach the Dive through `useDiveState`.
- AI chat:
  - Answers stream as they are written. Each answer shows the SQL it ran in an expandable receipt.
  - The assistant reads the selections stored by the Dive, so follow-up questions take the current filters into account.
  - Three model tiers are available, and administrators can restrict which tiers users see.
- A setup command reports the missing settings by name without printing any values. Its `--live` mode checks the embed session, the database connection and OpenAI model access. ([Configuration reference](https://github.com/leonardovida/motherduck-dive-ai-chat-starter/blob/v0.1.0/docs/configuration.md))
- The Vercel Deploy Button prompts for every required setting. ([README](https://github.com/leonardovida/motherduck-dive-ai-chat-starter/blob/v0.1.0/README.md#option-3-deploy-to-vercel))
- Coding agents that read `CLAUDE.md` now load the same instructions as agents that read `AGENTS.md`.

## Compatibility

- The starter requires Node.js 24, 25 or 26.
- In production, sign-in requires `DEMO_PASSWORD` and a `SESSION_SECRET` of at least 32 characters. Deployments on hosts other than Vercel also require `AUTH_TRUSTED_IP_HEADER`.
- AI chat runs read-only queries. The SQL guard rejects writes, file readers, external locations and dynamic SQL. Data access is enforced by the grants of the read-only MotherDuck identity.
