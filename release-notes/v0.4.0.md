## Highlights

- Every question asked in chat is now tracked in the app database with its outcome, the asker's groups and the Dive state at the time. Answers record whether they were answered, failed or stopped. ([Track questions in MotherDuck](https://github.com/leonardovida/motherduck-dive-ai-chat-starter/blob/v0.4.0/docs/accounts.md#track-questions-in-motherduck), [#7](https://github.com/leonardovida/motherduck-dive-ai-chat-starter/pull/7))
- People can rate each answer as helpful or not helpful directly in the chat panel. ([Saved conversations and privacy](https://github.com/leonardovida/motherduck-dive-ai-chat-starter/blob/v0.4.0/docs/accounts.md#saved-conversations-and-privacy), [#7](https://github.com/leonardovida/motherduck-dive-ai-chat-starter/pull/7))
- A new **Questions** tab in the admin portal shows question volume, outcomes, ratings, the most asked questions and the answers that need attention, by Dive, group and model. A `chat_questions` view makes the same data available to any MotherDuck client or Dive. ([The admin portal](https://github.com/leonardovida/motherduck-dive-ai-chat-starter/blob/v0.4.0/docs/accounts.md#the-admin-portal), [#7](https://github.com/leonardovida/motherduck-dive-ai-chat-starter/pull/7))

## Upgrading from v0.3

This release is a minor version because it adds features and new columns to the app database. Deployments pinned to `v0.3.x` do not receive it automatically.

1. Fetch the `v0.4.0` tag and merge it into a new branch, keeping the local Dives, `dives.config.mjs` entries and branding. The steps are in [AGENTS.md](https://github.com/leonardovida/motherduck-dive-ai-chat-starter/blob/v0.4.0/AGENTS.md#upgrade-a-copy-to-a-newer-template-version).
2. Run `npm ci`.
3. Run `npm run db:migrate` before deploying the new version. It adds six columns to `chat_message` and creates the `chat_questions` view. Until the migration has run, new conversations are not saved, although chat keeps answering, and the **Questions** tab asks for the migration.
4. Run `npm test` and `npm run build`, then check the chat panel and the **Questions** tab in a browser before deploying.

Review the [Compatibility](#compatibility) section for the additional data stored with each question.

## Features

- Question tracking ([#7](https://github.com/leonardovida/motherduck-dive-ai-chat-starter/pull/7)):
  - Each question stores the asker's group names and the Dive state (its filters and selections, up to 8 KB).
  - Each answer stores its outcome (`answered`, `failed` or `stopped`), a link to its question and the asker's rating.
  - The `chat_questions` view pairs each question with its answer, one row per question. Answers saved by earlier versions are paired by their order in the conversation, and their outcome is read from the saved text.
  - The documentation lists the view's columns and gives example SQL for weekly volume, questions per group and answers to review.
- Answer ratings ([#7](https://github.com/leonardovida/motherduck-dive-ai-chat-starter/pull/7)):
  - **Helpful** and **Not helpful** buttons appear below each saved answer. Pressing the active button again removes the rating.
  - Only the person who asked can rate an answer. The buttons appear only when conversations are saved.
- **Questions** tab in the admin portal ([#7](https://github.com/leonardovida/motherduck-dive-ai-chat-starter/pull/7)):
  - Filters by period (7, 30 or 90 days, or 12 months), Dive and group.
  - Totals for questions, people and conversations, the share answered, failed and stopped, the ratings and the typical answer time.
  - A chart of questions per day, with the questions that need attention shown separately. Hovering a day shows its numbers, and screen readers receive the same figures as a table.
  - **Needs attention** lists the newest failed or stopped answers and answers rated not helpful. **Most asked** groups questions that differ only in case, spacing or closing punctuation. Each entry opens its conversation.
  - Breakdowns by Dive, group and model.
  - **Export CSV** downloads the filtered questions without their answers. Each export is recorded in **Activity**.
- **Conversations** tab ([#7](https://github.com/leonardovida/motherduck-dive-ai-chat-starter/pull/7)):
  - A filter shows only conversations with a failed or stopped answer or a thumbs down.
  - The list and the conversation view show outcome and rating badges.
  - Each question shows the groups of the person who asked and the Dive state at the time.

## Bug Fixes

- The admin portal now switches tabs when only the `#tab` part of its address changes, for example through a link or an edit in the address bar. Previously, the tab changed only after a full page reload. ([#7](https://github.com/leonardovida/motherduck-dive-ai-chat-starter/pull/7))
- Long-running servers no longer add an error listener to the app database connection pool on every query. Previously, this produced a memory leak warning in the server logs over time. ([#7](https://github.com/leonardovida/motherduck-dive-ai-chat-starter/pull/7))
- CSV exports from the admin portal now prefix cells that a spreadsheet would run as a formula with a quote. This applies to the new questions export and to the existing people export. ([#7](https://github.com/leonardovida/motherduck-dive-ai-chat-starter/pull/7))

## Compatibility

- Saved questions now include the asker's group names and the Dive state. Deployments that describe their data retention to users should mention both. `CHAT_HISTORY=off` and `CHAT_RETENTION_DAYS` apply to them as before. ([Saved conversations and privacy](https://github.com/leonardovida/motherduck-dive-ai-chat-starter/blob/v0.4.0/docs/accounts.md#saved-conversations-and-privacy))
- `npm run db:migrate` is required. See [Upgrading from v0.3](#upgrading-from-v03).
- The `chat_questions` view reads the app database, which also holds accounts and sessions. Dashboards built on it should read a separate copy rather than a share of the app database. ([Track questions in MotherDuck](https://github.com/leonardovida/motherduck-dive-ai-chat-starter/blob/v0.4.0/docs/accounts.md#track-questions-in-motherduck))
