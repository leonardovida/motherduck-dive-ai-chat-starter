## Highlights

- Group managers can no longer act on people who also have Dives or chat granted to them directly, and **Set password** now signs the person out everywhere. Both close ways in which a manager or a former session could keep more access than intended. ([Group managers](https://github.com/leonardovida/motherduck-dive-ai-chat-starter/blob/v0.5.1/docs/accounts.md#group-managers), [#10](https://github.com/leonardovida/motherduck-dive-ai-chat-starter/pull/10))
- Answers that recover from a failed query are now saved as answered, and stopped answers keep their token usage, so question outcomes, cost estimates and group allowances are accurate. ([#10](https://github.com/leonardovida/motherduck-dive-ai-chat-starter/pull/10))
- Closing chat or switching Dives during an answer now stops it cleanly, and several smaller interface problems are fixed. ([#10](https://github.com/leonardovida/motherduck-dive-ai-chat-starter/pull/10))

## Upgrading from v0.5.0

This release is a patch version. Deployments that allow `~0.5.0` or `^0.5.0` receive it. It adds no settings and no database changes, so `npm run db:migrate` is not required.

1. Fetch the `v0.5.1` tag and merge it into a new branch, keeping the local Dives, `dives.config.mjs` entries and branding. The steps are in [AGENTS.md](https://github.com/leonardovida/motherduck-dive-ai-chat-starter/blob/v0.5.1/AGENTS.md#upgrade-a-copy-to-a-newer-template-version).
2. Run `npm ci`, `npm test` and `npm run build`.
3. Review the [Compatibility](#compatibility) section, in particular the change for group managers.

## Bug Fixes

- Access and accounts ([#10](https://github.com/leonardovida/motherduck-dive-ai-chat-starter/pull/10)):
  - A group manager could create a setup link for a person who also had Dives or chat granted directly by an administrator, and then sign in as that person. Such people are now outside a manager's reach.
  - **Set password** replaced the password but left the person's other sessions and any unused setup link working. Both now end.
  - Any signed-in person could change their own display name, including to another person's name, which then appeared in the admin portal. Profile changes are now refused outside the administrator tools.
  - The per-account sign-in limit could be cleared by trying many other usernames. Blocked accounts now stay blocked.
  - The read-only query check accepted file names written without quotes, such as `FROM x.csv`. These are now refused like quoted ones.
  - Request bodies on the remaining admin and setup routes are now limited in size.
  - Messages saved before `CHAT_HISTORY=off` was set were never deleted under `CHAT_RETENTION_DAYS`. They now expire, and conversation titles no longer keep the text of deleted questions.
  - The **Questions** summary for group managers no longer includes conversation ids. Deleting a conversation that does not exist now returns 404. Confirming the manual MotherDuck SQL no longer records grants made by other people as the app's own.
- Chat and models ([#10](https://github.com/leonardovida/motherduck-dive-ai-chat-starter/pull/10)):
  - When a tool call failed and the model then answered correctly, the answer was saved as failed and lost its suggested follow-up questions. It is now saved as answered. Query errors are passed to the model so that it can correct the query.
  - A stopped answer was saved without its token usage or tool steps, so stopping an answer did not count toward a group's monthly allowance. Both are now saved.
  - When Auto routing escalated to a stronger tier, the stronger tier kept the reasoning setting of the first one. It now uses its own.
  - **Retry** after a failed answer saved the question a second time. It now reuses the question and replaces the failed answer.
  - A response that broke off during streaming left its question without an answer record. It is now saved as failed.
  - Google Vertex AI switched to API key mode when `GOOGLE_VERTEX_API_KEY` was set next to a service account. The service account now takes precedence, as documented.
  - **Test** in **Models** tested the saved provider of a tier even after **Use the environment** was selected. It now tests the environment configuration.
  - A settings read that finished after an administrator saved new settings could restore the previous settings for up to 15 seconds.
- Interface ([#10](https://github.com/leonardovida/motherduck-dive-ai-chat-starter/pull/10)):
  - Closing chat or switching Dives during an answer cut it off without notice. It now stops the answer as **Stop** does.
  - When the embed route reported an ended session while the page still appeared signed in, the page could reload repeatedly for up to a minute. It now reloads once.
  - An unexpected theme value in browser storage prevented the Dive from loading. A stored dark theme also briefly showed the light theme on load. Both are fixed.
  - A collapsed sidebar could still be reached with the keyboard. The export error message can now be dismissed.
  - In the admin portal, a new setup link could disappear before it was copied, unsaved group edits were lost when a member was added, and a conversation opened from **Questions** reopened on later visits to **Conversations**.
  - Long Dive titles are shortened with an ellipsis. A failed sign-out and a failed sign-in after setting a password are now explained on screen.

## Compatibility

- Group managers no longer see the actions for people who also have Dives or chat granted directly, or who belong to another group. Administrators manage those people. To hand a person back to a manager, remove their own access in **People** so that only the group grants access. ([Group managers](https://github.com/leonardovida/motherduck-dive-ai-chat-starter/blob/v0.5.1/docs/accounts.md#group-managers))
- `POST /api/account/update-user` now returns 403. The included app does not use it. Administrators continue to edit people through the admin portal.
- Queries written by the assistant that name a file without quotes in a table position, such as `SELECT * FROM data.csv`, are now refused. Tables in the Dive's database are not affected.
